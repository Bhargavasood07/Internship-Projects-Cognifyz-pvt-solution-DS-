## 🚀 About the Internship

Welcome to my **Data Science Internship Project Repository at Cognifyz Technologies!**

This repository showcases the practical tasks and projects completed as part of my Data Science internship. The internship provided an opportunity to work with a real-world restaurant dataset and apply various data science techniques, ranging from data exploration and preprocessing to feature engineering, predictive modeling, and data visualization.

The project is organized into **three progressive levels, each containing three tasks**, focusing on developing practical analytical and problem-solving skills.

Through these projects, I explored how data can uncover hidden patterns, identify customer preferences, understand business performance, and support data-driven decision-making.

## 🎯 Project Objectives

- Understand and explore real-world restaurant datasets.
- Perform data cleaning and preprocessing.
- Apply descriptive and exploratory data analysis (EDA).
- Analyze restaurant trends across cuisines, cities, and locations.
- Investigate customer preferences and restaurant ratings.
- Perform feature engineering to extract meaningful information.
- Develop predictive models using machine learning techniques.
- Create insightful visualizations to communicate analytical findings.

# 📚 Internship Tasks – Level Wise Breakdown

## 🔰 Level 1 – Data Exploration & Analysis

**Objective:** Understand the restaurant dataset, explore its characteristics, and identify meaningful patterns through statistical and geographical analysis.

### 📌 Task 1: Data Exploration and Preprocessing

- Explored the restaurant dataset to understand its structure and dimensions.
- Identified the number of rows and columns.
- Examined data types and individual column information.
- Identified missing values and handled data inconsistencies.
- Analyzed the distribution of the Aggregate Rating variable.
- Explored the dataset to understand its overall quality and characteristics.

**Key Learning:** Understanding dataset structure, data cleaning, preprocessing, and initial exploratory analysis.

### 📌 Task 2: Descriptive Analysis

- Calculated statistical measures such as mean, median, and standard deviation.
- Analyzed categorical variables, including Country Code, City, and Cuisines.
- Identified the most common cuisines.
- Explored cities with the highest number of restaurants.
- Examined numerical and categorical data distributions.
- Extracted meaningful insights from descriptive statistics.

**Key Learning:** Statistical analysis, categorical data exploration, and identifying patterns within datasets.

### 📌 Task 3: Geospatial Analysis

- Visualized restaurant locations using latitude and longitude coordinates.
- Explored restaurant distribution across different cities and countries.
- Analyzed geographical patterns in restaurant availability.
- Examined the relationship between restaurant locations and aggregate ratings.
- Used geographical visualizations to understand location-based trends.

**Key Learning:** Geospatial data analysis, geographical visualization, and location-based insights.

---

## ⚙️ Level 2 – Restaurant Business Analysis & Feature Engineering

**Objective:** Analyze restaurant business characteristics, understand customer accessibility, and extract additional information from existing dataset features.

### 📌 Task 1: Table Booking and Online Delivery

- Calculated the percentage of restaurants offering table booking.
- Analyzed the availability of online delivery services.
- Compared average ratings of restaurants with and without table booking.
- Explored online delivery availability across different price ranges.
- Identified patterns between restaurant services and customer ratings.

**Key Learning:** Business analysis, percentage calculations, and comparative data analysis.

### 📌 Task 2: Price Range Analysis

- Analyzed the distribution of restaurants across different price ranges.
- Identified the most common restaurant price range.
- Calculated average ratings for each price category.
- Compared restaurant ratings across different pricing levels.
- Visualized price range distributions and rating comparisons.

**Key Learning:** Price-based analysis, grouping, aggregation, and comparative visualization.

### 📌 Task 3: Feature Engineering

- Extracted additional information from existing dataset columns.
- Calculated restaurant name length.
- Calculated restaurant address length.
- Created a `Has Table Booking` feature.
- Created a `Has Online Delivery` feature.
- Transformed existing information into meaningful analytical features.

**Key Learning:** Feature extraction, data transformation, and preparing datasets for further analysis.

---

## 🤖 Level 3 – Predictive Modeling, Customer Preferences & Data Visualization

**Objective:** Apply advanced analytical techniques to understand customer behavior, explore restaurant ratings, and generate meaningful insights through predictive modeling and visualization.

### 📌 Task 1: Predictive Modeling

- Prepared the restaurant dataset for predictive analysis.
- Selected relevant features for modeling.
- Performed data preprocessing and feature preparation.
- Developed machine learning models to predict restaurant aggregate ratings.
- Evaluated model performance using appropriate evaluation metrics.
- Explored the relationship between input features and predicted ratings.

**Key Learning:** Machine learning fundamentals, regression analysis, model training, and performance evaluation.

### 📌 Task 2: Customer Preference Analysis

- Analyzed the relationship between cuisine types and restaurant ratings.
- Identified popular cuisines based on total customer votes.
- Explored cuisines with higher average ratings.
- Compared cuisine-wise ratings to understand customer preferences.
- Identified patterns in customer engagement and restaurant popularity.

**Key Learning:** Customer preference analysis, cuisine-based comparisons, and understanding customer behavior through data.

### 📌 Task 3: Data Visualization

- Created visualizations to understand the distribution of restaurant ratings.
- Used different charts, including histograms and bar plots.
- Compared average ratings across different cuisines and cities.
- Explored relationships between different dataset features and the target variable.
- Presented analytical findings through meaningful graphical representations.

**Key Learning:** Advanced data visualization, exploratory data analysis, and communicating insights effectively.

## ⚡ Installation & Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/Bhargavasood07/Internship-Projects-Cognifyz-pvt-solution-DS-.git
```

**2. Navigate to the project directory**

```bash
cd Internship-Projects-Cognifyz-pvt-solution-DS-
```

**3. Install the required libraries**

```bash

```

**4. Launch Jupyter Notebook**

```bash

```

**5. Open the required task notebook or Python file and execute the cells.**
